## نظرة عامة

**WIT (Warframe Item Tracker)** هو تطبيق مرافق لـ Warframe يساعد في إدارة الصناعة وReliquies وذخيرة Prime وmastery ودورات العالم المفتوح وAmps المشغّل — كل شيء في مكان واحد، دون حساب. قابل للتثبيت كـ **Progressive Web App (PWA)**، يعمل دون اتصال بعد التحميل الأول. كل البيانات في localStorage. لا يوجد telemetry ولا تسجيل.

---

## المميزات

- **لوحة التحكم** — نظرة عامة لكل المتتبعات مع رسوم بيانية ومؤقتات مباشرة
- **Craft Tracker** — أضف العناصر، شاهد الموارد، أعد الترتيب بالسحب
- **Relic Tracker** — أي relics تُسقط أي أجزاء Prime، مزامنة ثنائية
- **Vault** — أدر أجزاء Prime، شاهد أي مجموعات يمكنك إكمالها
- **Mastery Tracker** — 820+ عنصر مع مفتاح ثلاثي الحالات (مملوك / متقن / لا شيء)
- **World Timers** — عد تنازلي لـ Cetus وFortuna وDeimos + Baro Ki'Teer
- **نظام Amp** — باني Amp، متتبع الأجزاء، مخطط Eidolon، مجموعات Meta
- **10 لغات** — العربية والإنجليزية والتركية والألمانية والفرنسية والإسبانية والإيطالية والبرتغالية والروسية واليابانية
- **3 سمات + محرر** — Orokin (ذهبي)، Drifter (أخضر)، Lotus (فاتح) مع مؤشرات ديناميكية
- **PWA** — قابل للتثبيت كتطبيق سطح مكتب/موبايل، يعمل دون اتصال

## بدء سريع

متطلب: [Node.js 18+](https://nodejs.org)

- Windows: نقر مزدوج على `start.bat`
- macOS / Linux: `./start.sh`

ثم افتح **http://localhost:3444** في المتصفح.
