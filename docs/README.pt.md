## Visão geral

**WIT (Warframe Item Tracker)** é um app complementar para Warframe que ajuda a gerenciar crafting, relíquias Void, inventário Prime, mastery, ciclos de mundo aberto e Amps de Operador — tudo num só lugar, sem conta. Instalável como **Progressive Web App (PWA)**, funciona offline após o primeiro carregamento. Todos os dados ficam no localStorage. Sem telemetria, sem cadastro.

---

## Recursos

- **Painel** — Visão geral de todos os trackers com gráficos e timers ao vivo
- **Craft Tracker** — Adicione itens, veja os recursos, reordene arrastando
- **Relic Tracker** — Quais relíquias dropam quais partes Prime, sincronização bidirecional
- **Cofre** — Gerencie suas partes Prime, veja quais sets pode completar
- **Mastery Tracker** — 820+ itens com botão de 3 estados (possuído / dominado / nenhum)
- **World Timers** — Contagem regressiva para Cetus, Fortuna, Deimos + Baro Ki'Teer
- **Sistema Amp** — Builder Amp, rastreador de partes, planejador Eidolon, sets Meta
- **10 idiomas** — Português, inglês, turco, alemão, francês, espanhol, italiano, russo, japonês, árabe
- **3 temas + editor** — Orokin (ouro), Drifter (verde), Lotus (claro) com cursores dinâmicos
- **PWA** — Instalável como app desktop/mobile, funciona offline

## Início rápido

Pré-requisito: [Node.js 18+](https://nodejs.org)

- Windows: clique duplo em `start.bat`
- macOS / Linux: `./start.sh`

Depois abra **http://localhost:3444** no navegador.
