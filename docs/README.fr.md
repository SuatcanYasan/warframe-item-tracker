## Aperçu

**WIT (Warframe Item Tracker)** est une application compagnon pour Warframe qui aide à gérer craft, reliques Void, inventaire Prime, mastery, cycles de monde ouvert et Amps Opérateur — le tout au même endroit, sans compte. Installable en tant que **Progressive Web App (PWA)**, fonctionne hors ligne après le premier chargement. Toutes les données restent dans le localStorage. Pas de télémétrie, pas d'inscription.

---

## Fonctionnalités

- **Tableau de bord** — Vue d'ensemble de tous les trackers avec graphiques et timers live
- **Craft Tracker** — Ajoutez des items, voyez les ressources, réorganisez par glisser-déposer
- **Relic Tracker** — Quelles reliques droppent quelles parties Prime, sync bidirectionnelle
- **Coffre** — Gérez vos parties Prime, voyez quels sets sont réalisables
- **Mastery Tracker** — 820+ items avec bascule à 3 états (possédé / maîtrisé / aucun)
- **World Timers** — Compte à rebours en direct pour Cetus, Fortuna, Deimos + Baro Ki'Teer
- **Système Amp** — Builder Amp Opérateur, suivi parties, planificateur Eidolon, sets Meta
- **10 langues** — Français, anglais, turc, allemand, espagnol, italien, portugais, russe, japonais, arabe
- **3 thèmes + éditeur** — Orokin (or), Drifter (vert), Lotus (clair) avec curseurs personnalisés dynamiques
- **Activités** — Fissures, Invasions, Nightwave, Sortie, Archon Hunt, Arbitration en direct dans un seul flux, actualisé toutes les 60s
- **Checklist** — Tâches quotidiennes/hebdomadaires Warframe avec réinitialisation automatique à UTC 00:00 et pack de presets
- **Partage par URL** — Partage tes données de tracker par lien compressé DEFLATE, sans backend
- **Farm Planner** — rechercher des ressources, définir une quantité cible, voir les lieux de drop et repérer les spots partagés pour plusieurs ressources
- **Synchronisation Cloud** — tes données se synchronisent automatiquement sur tous tes appareils via Supabase (compte anonyme, Realtime cross-device)
- **Export Screenshot** — export PNG en un clic de la vue actuelle (html-to-image)
- **PWA** — Installable comme app desktop/mobile, fonctionne hors ligne

## Démarrage rapide

Prérequis : [Node.js 18+](https://nodejs.org)

- Windows : double-clic sur `start.bat`
- macOS / Linux : `./start.sh`

Puis ouvrez **http://localhost:3444** dans votre navigateur.
