## 概要

**WIT (Warframe Item Tracker)** は Warframe のコンパニオンアプリで、クラフト、Void レリック、Prime インベントリ、mastery、オープンワールドサイクル、オペレーター Amp を一箇所で管理できます。アカウント不要。**Progressive Web App (PWA)** としてインストール可能で、初回ロード後はオフラインで動作します。全データは localStorage に保存。テレメトリなし、登録不要。

---

## 機能

- **ダッシュボード** — すべてのトラッカーの概要、進捗グラフとライブタイマー
- **Craft Tracker** — アイテムを追加、リソース要件を確認、ドラッグで並べ替え
- **Relic Tracker** — どのレリックがどの Prime パーツをドロップするか、双方向同期
- **Vault** — Prime パーツを管理、完成できるセットを確認
- **Mastery Tracker** — 820+ アイテムを3状態スイッチで管理（所持 / 習得 / なし）
- **World Timers** — Cetus、Fortuna、Deimos + Baro Ki'Teer のライブカウントダウン
- **Amp システム** — Amp ビルダー、パーツ追跡、Eidolon プランナー、Meta セット
- **10言語対応** — 日本語、英語、トルコ語、ドイツ語、フランス語、スペイン語、イタリア語、ポルトガル語、ロシア語、アラビア語
- **3テーマ + エディタ** — Orokin（金）、Drifter（緑）、Lotus（明）に動的カーソル
- **アクティビティ** — Fissures、Invasions、Nightwave、Sortie、Archon Hunt、Arbitration を1つのフィードでライブ追跡、60秒ごとに更新
- **チェックリスト** — デイリー/ウィークリー Warframe タスクを UTC 00:00 自動リセット、プリセットパック付き
- **URL 共有** — トラッカーデータを DEFLATE 圧縮リンクで共有、バックエンド不要
- **Discord Webhook** — Amp セット / Craft / Prime / Mastery 完成時に Discord チャンネルへリッチ embed ("尊敬する Tenno ..."), スパム対策付き
- **Farm Planner** — リソース検索、目標数設定、ドロップ場所表示、複数リソースの共通ファームスポット発見
- **スクリーンショットエクスポート** — 現在の画面をワンクリックで PNG エクスポート (html-to-image)
- **PWA** — デスクトップ/モバイルアプリとしてインストール可能、オフライン動作

## クイックスタート

必須: [Node.js 18+](https://nodejs.org)

- Windows: `start.bat` をダブルクリック
- macOS / Linux: `./start.sh`

ブラウザで **http://localhost:3444** を開く。
