## Panoramica

**WIT (Warframe Item Tracker)** è un'app companion per Warframe che aiuta a gestire crafting, reliquie Void, inventario Prime, mastery, cicli del mondo aperto e Amp dell'Operatore — tutto in un unico posto, senza account. Installabile come **Progressive Web App (PWA)**, funziona offline dopo il primo caricamento. Tutti i dati restano nel localStorage. Nessuna telemetria, nessuna registrazione.

---

## Funzionalità

- **Dashboard** — Panoramica di tutti i tracker con grafici e timer in tempo reale
- **Craft Tracker** — Aggiungi item, vedi i materiali richiesti, riordina trascinando
- **Relic Tracker** — Quali reliquie droppano quali parti Prime, sincronizzazione bidirezionale
- **Caveau** — Gestisci le tue parti Prime, vedi quali set puoi completare
- **Mastery Tracker** — 820+ item con switch a 3 stati (posseduto / maestrato / nessuno)
- **World Timers** — Conto alla rovescia per Cetus, Fortuna, Deimos + Baro Ki'Teer
- **Sistema Amp** — Builder Amp, tracker parti, pianificatore Eidolon, set Meta
- **10 lingue** — Italiano, inglese, turco, tedesco, francese, spagnolo, portoghese, russo, giapponese, arabo
- **3 temi + editor** — Orokin (oro), Drifter (verde), Lotus (chiaro) con cursori dinamici
- **Attività** — Fissures, Invasions, Nightwave, Sortie, Archon Hunt, Arbitration in diretta in un unico feed, aggiornato ogni 60s
- **Checklist** — Attività giornaliere/settimanali Warframe con reset automatico a UTC 00:00 e pacchetto di preset
- **Condivisione URL** — Condividi i dati del tracker come link compresso DEFLATE, senza backend
- **Discord Webhook** — Embed ricchi ("Stimato Tenno ...") nel tuo canale Discord al completamento di set Amp, craft, Prime o Mastery, con protezione anti-spam
- **PWA** — Installabile come app desktop/mobile, funziona offline

## Avvio rapido

Prerequisito: [Node.js 18+](https://nodejs.org)

- Windows: doppio clic su `start.bat`
- macOS / Linux: `./start.sh`

Poi apri **http://localhost:3444** nel browser.
