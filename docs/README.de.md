## Überblick

**WIT (Warframe Item Tracker)** ist eine Begleit-App für Warframe, die bei Craft, Void-Reliquien, Prime-Inventar, Mastery, Open-World-Zyklen und Operator-Amp-Management hilft — alles an einem Ort, ohne Konto. Als **Progressive Web App (PWA)** installierbar, funktioniert offline nach dem ersten Laden. Alle Daten bleiben im Browser-localStorage. Keine Telemetrie, keine Anmeldung.

---

## Funktionen

- **Dashboard** — Übersicht aller Tracker mit Fortschrittsdiagrammen und Live-Welttimern
- **Craft Tracker** — Items hinzufügen, Ressourcenbedarf sehen, per Drag & Drop sortieren
- **Relic Tracker** — Welche Reliquien droppen welche Prime-Teile, bidirektionale Sync mit Craft Tracker
- **Vault** — Prime-Teile verwalten, welche Sets du vervollständigen kannst
- **Mastery Tracker** — 820+ Items mit 3-Zustand-Toggle (besessen / gemeistert / keins)
- **World Timers** — Live-Countdown für Cetus, Fortuna, Deimos + Baro Ki'Teer
- **Amp System** — Operator-Amp-Builder, Teile-Tracker, Eidolon-Planer, Meta-Sets
- **10 Sprachen** — Deutsch, Englisch, Türkisch, Französisch, Spanisch, Italienisch, Portugiesisch, Russisch, Japanisch, Arabisch
- **3 Themes + Editor** — Orokin (Gold), Drifter (Grün), Lotus (Hell) mit dynamischen Custom-Cursorn
- **Aktivitäten** — Fissures, Invasions, Nightwave, Sortie, Archon Hunt, Arbitration live in einem Feed, alle 60s aktualisiert
- **Checkliste** — Tägliche/wöchentliche Warframe-Aufgaben mit automatischem UTC 00:00 Reset und Preset-Paket
- **URL-Freigabe** — Tracker-Daten als DEFLATE-komprimierten Link teilen, ohne Backend
- **Farm-Planner** — Ressourcen suchen, Zielmenge setzen, Drop-Orte ansehen und gemeinsame Farm-Spots für mehrere Ressourcen finden
- **Cloud-Sync** — deine Daten synchronisieren sich automatisch auf allen Geräten via Supabase (anonymer Account, Realtime cross-device)
- **Screenshot-Export** — One-Click PNG-Export deiner aktuellen Ansicht (html-to-image)
- **PWA** — Installierbar als Desktop-/Mobile-App, funktioniert offline

## Schnellstart

Voraussetzung: [Node.js 18+](https://nodejs.org)

- Windows: Doppelklick auf `start.bat`
- macOS / Linux: `./start.sh`

Dann öffne **http://localhost:3444** im Browser.
